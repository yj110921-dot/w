# 모바일 청첩장

윤상제, 이진실 모바일 청첩장 시안입니다.

## 현재 구성

- 표지
- 초대 문구
- 사진 갤러리 자리
- 2026년 11월 달력
- 예식장 위치
- 계좌 안내 영역
- 마무리 문구

## 사진 넣는 법

사진 파일은 `assets` 폴더에 넣고 `index.html`의 갤러리 영역을 이미지 태그로 교체하면 됩니다.
예: `assets/photo-1.jpg`

## 배포

GitHub Pages 배포 시 `index.html`, `styles.css`, `script.js`, `assets` 폴더가 저장소 루트에 있으면 됩니다.
